# OCTUBER：授權比價資料的顯示規則

## 使用者介面

使用者確認曾向 BigGo、飛比、LBJ 的公司私訊詢問且獲得允許。此項陳述記為**使用者自述的合作允許**，不是公開可驗證的 API 契約或已具備自動下載能力。需要依實際回覆範圍區分查詢、匯入、保存、商業展示、模型訓練與大量自動擷取；如合作方另有強制公開署名條款，應依約遵守。

**介面對每筆報價的呈現：** 顯示實際**販售平台／店鋪**，例如「蝦皮購物 · 優選數位店」、「酷澎 · 官方自營」、「momo購物網 · 直營」，以及商品規格、價格、實際觀察時間與商品頁連結。若沒有確實可信的販售平台，就只顯示店鋪名稱；絕不可用資料來源或 aggregator URL 推測平台。

**取得報價來源獨立記錄：** BigGo、飛比、LBJ 只在授權資料 CSV/JSON 的 `source` 欄位、從本機匯出的原始記錄與內部稽核流程保留。商品價格結果表不再逐筆顯示這些查價來源名稱，不代表刪除必要的授權歸屬與稽核依據。上方人工比價入口仍可使用。

## 匯入格式

可用 CSV：

```csv
product,sku,merchant,marketplace,source,price,observed_at,url,currency
示範耳機A,MODEL-001,示範賣家甲,shopee,feebee,1599,2026-10-24T10:00:00+08:00,https://example.org/sample-a,TWD
示範耳機A,MODEL-001,示範賣家乙,coupang,biggo,1699,2026-10-24T10:10:00+08:00,https://example.org/sample-b,TWD
```

**上面是純格式範例，價格不是任何真實網站報價，不得加入實價訓練。** 也接受 JSON array。商家名稱 `merchant` 保留；`marketplace` 可填 `shopee`（蝦皮）、`coupang`（酷澎）、`momo`、`pchome`、`yahoo`、`rakuten`，或對應中文平台名。缺資料可留空，無法確認不可猜測。`source` 值仍使用 `biggo`、`feebee`、`lbj`、`authorized-feed` 等取價記錄。

**避免錯誤商家判斷：** 若匯入列把 `merchant` 寫成 `BigGo`、`Feebee`、`飛比`、`LBJ` 等彙整站名稱，而非實際賣家，介面只會呈現「實際販售商家未確認」，並將該筆排除出依獨立店家計算的參考價；即使有平台欄位也不能將彙整站偽裝成平台上的獨立賣家。

## 與真實價格感訓練的區別

這次變更只負責**顯示規則、匯入資料規格與測試**，沒有自動呼叫 BigGo、飛比、LBJ，也沒有假稱已完成新的台灣商品價格權重訓練。大量 CSV/API 訓練仍需實際可取得的授權報價、SKU／規格對齊、不同商家去重、觀察時間與獨立測試；不得因取得網站名稱就假造一百萬筆商品記錄。

現行 Vanilla UI 每次最多匯入 500 筆且僅保存在瀏覽器，**不適合百萬筆訓練**。大型訓練資料應透過獨立受控後端／離線管線批次處理、保留合法取得證據和資料許可，並與介面存儲容量分開。

驗證命令：`npm run test:octuber-pricing`；完整 `npm run build`。正式上線另需人工審核。
