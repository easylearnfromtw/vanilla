# October / 阿土伯單一主控（Phase 1）

主聊天的生成模型只允許阿土伯 Qwen3 0.6B（裝置端）或使用者自行部署、明確命名的 October Ollama。其他模型不會在主模型失敗後自動接管。私密模式僅允許裝置端。一般工具仍保留既有權限、同意與後端驗證，不能宣稱已由神經網路自主完成。

此階段**沒有**把其他模型權重合併到 Qwen3；也**尚未**將所有獨立工具頁統一成由阿土伯主動規劃的工具流程。圖片聊天需先有受授權的視覺專家適配器，否則拒絕假稱能辨識。現有模型供應商仍可供獨立專家工具使用。

後續整合：阿土伯受限 JSON 計畫 → 伺服器端授權 → 受控工具／模型執行 → 實際回條驗證 → 阿土伯整合回答；需經超過 100 題的人工審核測試及 RTX 3050 真機效能驗證，再逐步開啟。

CI：`npm run test:model-tuning` 會涵蓋 336 組人工建構的候選模型配置政策檢驗；這不是 336 題真實語意測試。
