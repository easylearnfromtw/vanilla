# Vanilla 介面：Bauhaus Paper × Liquid Glass

來源：Vanilla 主視覺（米色紙、黑色 V、紅藍黃色塊、細黑構成線、字距拉開的幾何大寫字）。
原則：**內容是紙，控制是玻璃**。訊息、卡片、面板一律不透明紙面；頂欄、Tab bar、輸入框、膠囊、選單才用液態玻璃。

## 色票（`src/theme/vanilla-bauhaus.css` 的 `:root`）
| Token | 值 | 用途 |
| --- | --- | --- |
| `--paper` | `#f4eee6` | 背景（取自主視覺紙色） |
| `--card` | `#fbf8f3` | 不透明內容卡 |
| `--ink` | `#151515` | 文字、使用者訊息泡泡、主要按鈕 |
| `--red` | `#cd1f14` | CREAM／表格、標題方塊、停止鍵 |
| `--blue` | `#1446c8` | 搜尋／網頁、雲端模型、就緒狀態 |
| `--yellow` | `#f6be0b` | 記憶／檔案、本機模型、提示 |
字體：英文標示用 Futura／Avenir Next（iPhone 內建），中文與內文用系統字（蘋方）。

## 元件（簡約版：每個畫面只留必要的東西）
- **頂欄**：玻璃；對話頁顯示字距拉開的 `VANILLA AI`、新對話按鈕、帳號頭像。
- **模型膠囊**：對話頁上方唯一的控制，顯示「自動／本機／私密／未設定模型」；點開「模型與工具」面板（手機為底部面板），裡面才有一般／私密分段控制、本地模型、比較兩個答案、計費 API、自動附加資料（記憶、CREAM、專案、自動查證）、更多工具。
- **首頁**（照主視覺手機畫面）：V 標誌 → `VANILLA AI` 字標 → 置中輸入框 → 四個工具（對話／研究／建立／整理）→ 最近對話。沒有模型時只多一行提示與一顆按鈕。
- **訊息**：AI 頭像用 App icon；來源、工具標籤、參考資料都是淡色小字；複製／👍👎／⋯ 只出現在最新一則（舊訊息點一下才出現）。
- **輸入框**：玻璃膠囊、左側＋附件、右側黑色圓形送出（生成中變紅色停止鍵）；輸入 `/` 出現指令選單。下方不放其他東西。
- **狀態提示**：幾秒後自動淡出。
- **Tab bar（手機，對話以外的頁面）**：浮動玻璃膠囊；按住會放大，可拖曳膠囊到其他分頁後放開切換；往下捲縮小、鍵盤開啟時隱藏。對話頁不顯示，讓畫面保持乾淨。
- **側邊抽屜**：單色線條圖示，目前頁面以小紅方塊標示。
- **進場動畫**：訊息與首頁區塊 blur-fade；`prefers-reduced-motion` 時關閉。

## iOS 網頁／PWA 細節
- 所有輸入框 ≥16px（避免 iOS 自動放大）；`touch-action: manipulation` 移除點兩下延遲。
- `visualViewport` 追蹤鍵盤：輸入框保持在鍵盤上方、頂欄不被捲走、Tab bar 隱藏。
- Standalone 模式頂欄加上 `safe-area-inset-top`，底部元件加 `safe-area-inset-bottom`。
- `apple-touch-icon`（180/167/152）、manifest 圖示（192/512/maskable）都取自你的 App icon。
- 狀態列樣式 `default`（米色背景上用黑字）；`theme-color` 為紙色。
- 只自動載入已快取的本地模型，避免行動網路自動下載。
- 中文輸入法選字時按 Enter 不會誤送出（`isComposing` 判斷）。
- 支援 `prefers-reduced-transparency`；不支援 `backdrop-filter` 的瀏覽器改用不透明紙面。

## 沒做的效果
- 可拖曳的 SVG 位移折射鏡片：iOS Safari 不支援 `backdrop-filter: url(#svg)`，在 iPhone 上看不到，所以沒有加入。
