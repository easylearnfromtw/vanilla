# Vanilla 自適應語氣與 Self-Build（第一階段）

此功能在現有 `easylearnfromtw/vanilla` PWA 中運作，保留原本的 WebLLM／Ollama／Gemini／DeepSeek 及 Sheets／Files 模組。

## 1. 語氣自動適應

- 一般模式可根據使用者實際輸入訊息的 **長度、問句、標點比例、表情符號習慣** 更新一份小型統計設定；不保留原文或推斷心理診斷。
- 私密模式不參與學習。重設及關閉選項在「系統設定 → 對話同頻」。
- 可以設定直接程度、親近感、回答詳略以及模仿強度。
- 支援直接對 Vanilla 說：「之後回答簡短一點」「不要太正式」「以後停止模仿我的語氣」。符合明確指令時在本機更新，不消耗 API。
- 每則一般 AI 回答可以回饋「太正式／太囉嗦／太冷淡／語氣很像我」。
- 語氣偏好會成為本地 AI、Ollama、Gemini 的回覆提示，但並不改變模型權重，也不會訓練出新的模型。
- 使用者每則問題指定的格式、語氣或篇幅仍優先；不得因為模仿語氣而降低事實性、隱私或安全要求。
- 儲存位置：當前裝置的 localStorage。使用雲端模型時，僅把所需風格指引附加到該次提示；是否將聊天本文送出仍取決於原本的雲端模型同意設定。

## 2. Self-Build Studio

從左側進入「Self-Build Studio」，描述想要的功能。第一階段真正可執行的模組：

| 模組 | 執行能力 |
|---|---|
| Checklist | 本地待辦、新增刪除、標記完成、CSV |
| Tracker | 自訂最多 12 欄位、紀錄最多 200 筆、CSV |
| Calculator | 自訂數字輸入與安全四則運算，不執行 JS |
| Notes | 本機筆記與 TXT 匯出 |

### 產生方案

- **離線快速建立草稿**：不呼叫任何模型，會根據「記帳／運動／旅行／讀書／計算器／清單／筆記」等內容產生合理初始規格，讓你預覽。
- **AI 生成方案**：使用已載入的手機本地模型、使用者授權的 Ollama 或 Gemini；外部服務會先詢問是否傳送功能構想。
- **人工安裝**：所有提案都是單純 JSON 描述，必須先審核欄位與公式，再點選「確認安裝」。AI 的任意 JavaScript、HTML、eval、外部下載及網路授權都不會被執行。
- 安裝後出現在左側「我的自建工具」，可以再要求改進。
- 更新前會顯示新增／移除欄位、型別改變、公式更新等差異。風險較大的更動須再次確認。
- 最多保留 8 版舊功能規格供回復，資料和功能規格分開保存，回復規格不直接刪除紀錄。
- 刪除功能和**刪除功能＋所有資料**是不同操作。後者需要二次確認。
- 支援匯出未加密 JSON 備份，匯入前驗證結構並預覽項目；匯入時建立獨立副本，不直接覆蓋現有模組。

### 聊天入口

## 3. 進階程式碼生成

如果需求超過四種資料型模組，例如要新增完整 RAG、不同 Google Drive 授權、資料庫／3D／大量 UI 組件，Studio 可產生工程需求並開啟預先填好的 GitHub Issue。

**目前並沒有由手機端自動取得 GitHub 寫入權限、修改 React 原始碼、建立 PR 或部署的代理。** 要建真正可受控的原始碼型 Self-Build，下一階段應由權限受限的後端／GitHub App 負責分支、白名單檔案修改、測試及 PR，經使用者審核後才能合併。不得將 GitHub Token 或長期 API Key 寫在 GitHub Pages 前端。

## 4. 驗收項目

GitHub Pages 工作流程先跑 `npm run test:workspace`、`npm run test:builder`，再執行 `npm run build`。新增測試涵蓋：

- 嚴格拒絕含 JS、外部命令及非法欄位的動態計算器
- 功能規格安裝、更新、版本回復與紀錄保留
- 普通對話的語氣學習、不儲存原文、私密模式不學習、停用／重置
- 將明確的聊天語氣偏好套用本機設定
- 離線草稿包含適當預設欄位、修改既有模組不直接刪資料
- 自建功能備份格式驗證及安全匯入不同 ID 的副本
- 高風險功能更新（移除欄位、改欄位型別）識別

還需在 iPhone PWA 上確認字型、側邊導覽、備份檔案分享、長欄位填寫與低記憶體載入的實際體驗。GitHub Actions 綠燈也不代表所有外部 API 可用。

## 5. 資料與費用

- 語氣設定、自建工具及紀錄目前只存本機，**不會自動與 Google Drive 同步**。
- 匯出的 JSON 備份**沒有加密**，不要無保護地分享敏感家庭或醫療資料。
- 離線規格建立不需要 token；AI 產生功能將依使用者選定的 Ollama／Gemini 模型及帳號實際額度可能產生費用。
- AI 安裝的模組規格不含外部網路操作能力；如果將來增加，需要額外權限模型。
