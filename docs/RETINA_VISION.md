# Retina · 圖片辨識與文件匯出

Retina 現在包含兩條獨立且可稽核的能力：

1. **圖片輸入與視覺模型派工**（`src/detroit/retina-vision.ts`）：Athena 掃描附件 → Retina 驗證格式與大小 → 裝置端轉檔（必要時）→ 經過既有雲端模型使用同意 → Gemini 的 inlineData 多模態推論 → Retina 在 Detroit 階段紀錄實際成功或失敗。
2. **本機文件匯出**（`src/detroit/retina.ts`）：使用者指定時產生 PDF、DOCX、PPTX，不依賴圖片辨識模型。

## 已實作

- 支援 JPEG／PNG／WebP；在瀏覽器有解碼支援時，可將 HEIC／HEIF／GIF／BMP／AVIF 以本機 Canvas 轉為 JPEG（長邊最長 2048px）。
- 單張上限 8 MB，拒絕空白檔、SVG 以及不支援的圖片格式；失敗時明確回報。
- 附上圖片時跳過純文字的意圖工具攔截，改派 Retina 和多模態模型。
- 只有 Gemini 支援圖片輸入；目前 WebLLM 手機模型、DeepSeek 與既有 Ollama 文字模型 **不會冒充圖片辨識**。
- 私密或指定「只用本地」時，若缺少真正可用的本地視覺模型，直接告知無法辨識，不將圖片傳給雲端，不降級到文字模型猜測。
- Retina 的開始、成功、失敗狀態在 Detroit 稽核流程顯示；避免把「計畫執行」標成「已執行」。

## 使用方式

1. 一般模式 → 設定連接有效的 Gemini API；在模型與工具中開啟雲端模型使用（需遵守提示的費用／權限）。
2. 按聊天輸入框的「+」，選取照片、手機截圖或 HEIC 圖片；輸入「請辨識這張圖片的文字」或直接送出圖片。
3. 首次向 Gemini 傳送聊天及圖片前，確認供應商資料傳送授權。辨識結果會出現在聊天，Retina 階段顯示真實狀態。

**隱私注意事項：** 圖片送到 Gemini 的授權，與既有 Vanilla 附件庫／Google Drive 自動備份流程是兩件事。一般模式中的附件仍會依既有設定嘗試本機保存或同步 Google Drive；私密模式不做持久化附件備份。辨識前的圖片轉檔在瀏覽器執行，無需另外上傳轉檔服務。

## 驗收檢查

- JPEG 截圖：確實識別圖片中文字並依圖片回答，而不是僅根據檔名推測。
- HEIC：可解碼時轉 JPEG；不可解碼時清楚提示轉檔，不默默傳空圖。
- SVG／空檔／大於 8 MB：阻擋並保留錯誤提示。
- 私密模式／明確只用本地：不可將圖片傳雲端，應顯示缺乏本地視覺模型。
- 只連接 DeepSeek 或沒有 Gemini：明確告知 Retina 尚缺圖片模型。
- 尚未同意雲端模型／使用者拒絕同意：不可呼叫 Gemini。
- Gemini API 回錯：顯示失敗；不退回純文字模型，不宣稱圖片已讀取。
- 原有 PDF／DOCX／PPTX 匯出回歸測試持續通過。

## 限制

尚未整合能完全在手機本地執行的圖片理解模型；目前真正的視覺語意辨識需要 Gemini。尚無多張圖片同步辨識、連續影格影片分析或離線全功能 OCR。不應將這些尚未部署的能力描述為已完成。
