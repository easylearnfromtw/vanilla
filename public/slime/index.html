STEP 02 — PAIR

查看 Telegram 配對碼

⌘

這是 Telegram Ceres 核發的同一組配對碼的唯讀顯示區，不會在網頁右側另外產生第二組。從 Owner 私聊中的專屬連結開啟，即可查看並複製。

來源：Telegram Ceres（唯一核發處） 尚未收到配對碼 前往 Telegram /hub → Slime → 產生配對碼，再點選「在獨立網頁開啟配對」

請勿輸入 Vanilla 模型 API Key、Gemini 金鑰、GitHub Token 或舊版 Detroit Windows Node 授權。右側不是另一組密碼，也不在此公開網頁驗證或核發節點 Token。首次安裝程式會透過 WeiGuo HTTPS 後端完成真正的配對。

STEP 03 — CONNECT

首次執行與連線

◈
  1. 01
    在電腦上開啟 Slime

    Windows 啟動 Slime-Owner.exe 或 Slime-Friend.exe。macOS、Linux 的壓縮包需 Python 3.10+ 與相對應啟動腳本。未有正式發行檔時，不可使用來源不明的安裝程式。

  2. 02
    貼上 12 位短配對碼

    輸入電腦名稱，貼上 Telegram 所核發、網頁右側唯讀顯示的同一組 12 位短碼。備用邀請連結含同一組短碼，不是另一組密碼。確認同意後，Slime 才會註冊此電腦。

  3. 03
    在 Telegram 確認裝置

    在 Ceres Telegram 私人管理頁確認「已加入」及「目前在線」；配對成功只代表已註冊，不等於 GPU 或 AI 模型已可使用。重開 Slime 不需重新輸入短碼。

  4. 04
    選擇性開啟 Ollama 推論

    安裝並啟動本地 Ollama，確認 Ceres 中的可用模型數，再由 Owner 核准推論。Vanilla API Key、Token 額度與模型權限由 Gateway 另行控制；核准後還需實際推論測試。

STEP 04 — MANAGE

安全與退出

◎

管理功能不會出現在公開下載頁。朋友版無法變更管理員權限；關閉程式可停止共享，正式退出需在本機使用 --leave 或由 Owner 撤銷節點。

安全背景模式：裝置持有人配對後，可自行選用 Windows 工作排程器、macOS LaunchAgent 或 Linux systemd user service。在使用者登入後可關閉螢幕繼續運算，不能讓睡眠／休眠／關機的主機保持計算，也不會隱藏硬體狀態燈。
